# 3.1 指数梯形离散化

Structured SSMs are naturally defined as continuous-time dynamical systems that map input functions, $x(t) \in \mathbb{R}$,  to output functions, $y(t) \in \mathbb{R}$, for time $t > 0$.

The underlying continuous state space system is defined by a first-order ordinary differential equation (ODE) for the state $\dot{\mathbf h}(t)$ and an algebraic equation for the output $y(t)$.

In sequence modeling, however, the data is only observed at discrete time steps, which then requires applying a discretization step to the SSM to transform its continuous-time dynamics into a discrete recurrence.

Discretization methods are well-studied in classical control theory with several canonical formulas used in earlier SSM works in deep learning.
These mechanisms were traditionally stated and applied to linear-time invariant (LTI) systems, and their derivations 推导 do not directly apply to linear-time varying (LTV) systems.

此外，尽管Mamba-1在没有证明的情况下将零阶保持（ZOH ）方法应用于LTV系统，但选择性SSM的复杂性促使人们使用一种额外的启发式近似方法，该方法缺乏理论依据，也不对应于任何已建立的离散化技术。在以下小节中，我们将通过我们的离散化框架形式化当前LTV SSM中使用的启发式方法，并利用该框架提出一种更具表达力的离散化方案。

# 3.1.1 指数调整离散化概述

我们提出了一种简单的推导方法，由此得到了一类用于线性时变状态空间模型的新型离散化方法。该方法可以以多种方式实现；我们证明其中一种实现方式（指数-欧拉法）与 Mamba-1/2 中使用的启发式算法一致，从而在理论上验证了该方法的合理性。此外，我们还引入了一种更强大的离散化方法（指数-梯形法），该方法已应用于 Mamba-3 中。

The high-level intuition of our derivation originates from the closed form solution $x(t) = e^{tA}x(0)$ of a simple linear ODE $x'(t) = Ax(t)$, which discretizes to $x_{t+1} = e^{\Delta A}x_t$.

In this example, the exponential dominates the dynamics of the underlying first-order ODE, resulting in imprecise不精确的 approximations when using low-order methods without significantly constraining $\Delta$.

Thus, we analyze the dynamics of the exponential-adjusted system $e^{-At}x(t)$. The adjusted system yields 产生 a discrete recurrent form where the state-transition and the state-input integrals 积分 are approximated separately---the state-transition integral is approximated by a right-hand approximation, i.e. $A(s):=A(\tau_t)$ for all $s \in [\tau_{t-1},\tau_t]$, yielding,$$\begin{align*}
    \mathbf h(\tau_t) &= \underbrace{\exp\left(\int_{\tau_{t-1}}^{\tau_t}A(s)ds\right)\mathbf h(\tau_{t-1})}_\text{via right-hand approximation} + \underbrace{\int_{\tau_{t-1}}^{\tau_t} \exp\left(\int_{\tau}^{\tau_t}A(s)ds\right)\mathbf B(\tau)x(\tau) d\tau}_\text{via different discretization schemes},
    \\
    \mathbf h_t &\approx \exp\left(\Delta_t A_t\right)\mathbf h_{t-1} + \int_{\tau_{t-1}}^{\tau_t} \exp\left((\tau_t -\tau)A_t\right)\mathbf B(\tau)x(\tau) d\tau,
\end{align*}$$

## 一、积分因子法推导

连续时间的状态方程是一个一阶线性时变常微分方程（LTV ODE）：

$$\frac{d\mathbf{h}(t)}{dt} = A(t)\mathbf{h}(t) + \mathbf{B}(t)x(t)$$

移项，把含 $\mathbf{h}(t)$ 的项放到左边：
$$\frac{d\mathbf{h}(t)}{dt} - A(t)\mathbf{h}(t) = \mathbf{B}(t)x(t)$$

直接对两边积分是算不出来的，因为左边既有 $\mathbf{h}(t)$ 又有它的导数。为了把左边凑成一个**单一函数的全导数**（即乘积求导法则 $\frac{d}{dt}[f(t)\mathbf{h}(t)]$），我们在方程两边同时乘以一个**积分因子** $\mu(t)$：
$$\mu(t) = \exp\left(-\int_{\tau_{t-1}}^{t} A(s)ds\right)$$

_(注：图片第一句话提到的 `exponential-adjusted system` $e^{-At}x(t)$ 指的就是乘上这个指数衰减因子的操作，当 $A$ 为时变矩阵 $A(s)$ 时，指数上的 $-At$ 就推广成了积分 $-\int A(s)ds$)_。
注意根据微积分基本定理，对 $\mu(t)$ 求导会得到：

$$\frac{d\mu(t)}{dt} = -\mu(t)A(t)$$

现在，将方程两边同时乘以 $\mu(t)$：
$$\underbrace{\mu(t)\frac{d\mathbf{h}(t)}{dt} - \mu(t)A(t)\mathbf{h}(t)}_{\text{正好等于 }\frac{d}{dt}\left[\mu(t)\mathbf{h}(t)\right]} = \mu(t)\mathbf{B}(t)x(t)$$

左边成功合并为全导数：
$$\frac{d}{dt}\left[\mu(t)\mathbf{h}(t)\right] = \mu(t)\mathbf{B}(t)x(t)$$

接下来，我们对时间变量（为了不和积分上限混淆，把积分变量改写为 $\tau$）从 $\tau_{t-1}$ 到 $\tau_t$ 做定积分：
$$\int_{\tau_{t-1}}^{\tau_t} \frac{d}{d\tau}\left[\mu(\tau)\mathbf{h}(\tau)\right] d\tau = \int_{\tau_{t-1}}^{\tau_t} \mu(\tau)\mathbf{B}(\tau)x(\tau) d\tau$$

左边直接用牛顿-莱布尼茨公式展开（注意 $\mu(\tau_{t-1}) = \exp(0) = I$）：对导数做定积分，等于原函数在上限的值减去在下限的值
$$\mu(\tau_t)\mathbf{h}(\tau_t) - \mathbf{h}(\tau_{t-1}) = \int_{\tau_{t-1}}^{\tau_t} \mu(\tau)\mathbf{B}(\tau)x(\tau) d\tau$$

把 $\mathbf{h}(\tau_{t-1})$ 移到右边，再两边同时除以 $\mu(\tau_t)$（即乘以它的逆 $\mu(\tau_t)^{-1} = \exp\left(\int_{\tau_{t-1}}^{\tau_t} A(s)ds\right)$）：
$$\mathbf{h}(\tau_t) = \mu(\tau_t)^{-1}\mathbf{h}(\tau_{t-1}) + \int_{\tau_{t-1}}^{\tau_t} \mu(\tau_t)^{-1}\mu(\tau)\mathbf{B}(\tau)x(\tau) d\tau$$

利用指数性质合并 $\mu(\tau_t)^{-1}\mu(\tau)$：定积分交换上下限会使积分结果变号

$$\exp\left(\int_{\tau_{t-1}}^{\tau_t} A(s)ds\right) \cdot \exp\left(-\int_{\tau_{t-1}}^{\tau} A(s)ds\right) = \exp\left(\int_{\tau}^{\tau_t} A(s)ds\right)$$

_(注：严格矩阵情况下这里假设 $A(s)$ 在不同时刻可交换，比如对角矩阵，这也是 Mamba/S5 等结构化 SSM 的核心假设)_。

代回原式，就得到了第一个公式：

$$\mathbf{h}(\tau_t) = \exp\left(\int_{\tau_{t-1}}^{\tau_t} A(s)ds\right)\mathbf{h}(\tau_{t-1}) + \int_{\tau_{t-1}}^{\tau_t} \exp\left(\int_{\tau}^{\tau_t} A(s)ds\right)\mathbf{B}(\tau)x(\tau) d\tau $$

### 二、 为什么会分别对 $ds$ 和 $d\tau$ 积分？（物理直觉与双重积分）

你看第二个积分项里套了一个**二重积分**：外层对 $d\tau$ 积分，内层指数上对 $ds$ 积分。这两个积分变量在物理时间轴上代表**完全不同的层级**：


```
时间轴:  τ_{t-1} ------------ τ -------------> τ_t
         |                    |                 |
         |--- 输入注入时刻 --->|                 |  (外层变量 τ：在 [τ_{t-1}, τ_t] 内遍历所有输入)
                              |<--- 衰减过程 --->|  (内层变量 s：在 [τ, τ_t] 内累积衰减率)
```

1. **为什么内层要对 $ds$ 积分？（计算“总衰减倍率”）**
    
    - 如果衰减率 $A$ 是个**常数**，从时刻 $\tau$ 到 $\tau_t$ 经过了 $(\tau_t - \tau)$ 秒，总衰减倍率直接就是 $e^{A(\tau_t - \tau)}$（乘法）。
    - 但这里是**时变系统（LTV）**，在 $[\tau, \tau_t]$ 这段路上，每一瞬间的衰减率 $A(s)$ 都在变化（就像你开车从 A 地到 B 地，速度 $v(s)$ 一直在变）。

    - 要算总路程，必须把路程切分成无数个微元 $ds$，用 $v(s)ds$ 积分；同理，要算从 $\tau$ 到 $\tau_t$ 的**累积衰减量**，就必须把时间切分成微元 $ds$，对时变的衰减率 $A(s)$ 做积分 $\int_{\tau}^{\tau_t} A(s)ds$，然后再取指数 $\exp(\cdot)$ 得到总衰减倍率。

2. **为什么外层要对 $d\tau$ 积分？（线性系统的“叠加原理”）**

    - 在 $[\tau_{t-1}, \tau_t]$ 这段时间里，外部输入 $x(\tau)$ 是**源源不断**注入系统的，而不是只在终点注入一次。

    - 想象往一个漏水的桶里倒水：

        - 在 $\tau$ 时刻倒入了一滴水，水量是 $\mathbf{B}(\tau)x(\tau)d\tau$。

        - 这滴水注入后，并不会原封不动留到 $\tau_t$，而是从 $\tau$ 时刻开始跟着桶一起漏水（经历 $[\tau, \tau_t]$ 的衰减，即乘以 $\exp\left(\int_{\tau}^{\tau_t} A(s)ds\right)$）。
    
        - 最终在 $\tau_t$ 时刻桶里还剩多少水？必须把从 $\tau_{t-1}$ 到 $\tau_t$ 之间**每一个时刻 $\tau$ 倒入的那一滴水**，乘上它各自的剩余比例，全部累加（积分）起来——这就是外层的 $\int_{\tau_{t-1}}^{\tau_t} (\cdots) d\tau$。

- **$ds$ 负责“纵向演化”**：给定一个起点 $\tau$ 和终点 $\tau_t$，把中间时变的系统动态 $A(s)$ 累积起来，算出状态传递的**放大/衰减系数**。

- **$d\tau$ 负责“横向叠加”**：把整个时间步 $[\tau_{t-1}, \tau_t]$ 内的连续输入切片，将每个切片经过各自演化后的残留贡献全部**求和**。


当你理解了这一层，再看**右端点近似** $A(s) := A(\tau_t)$ 就非常自然了：它其实就是假设在极短的时间步内“漏水速度恒定”，从而直接干掉了内层的 $\int ds$ 积分，把它简化回普通的乘法 $(\tau_t - \tau)A_t$。
