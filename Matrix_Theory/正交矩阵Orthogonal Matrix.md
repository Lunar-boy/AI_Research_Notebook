# 单位矩阵Identity Matrix
它是一个主对角线（从左上到右下）上的元素全为 $1$，其余所有位置全为 $0$** 的正方形矩阵（$n \times n$）。
用元素索引（克罗内克 $\delta$ 符号）来写，它的第 $i$ 行第 $j$ 列元素满足：
$$(I_n)_{ij} = \delta_{ij} = \begin{cases} 1, & i = j \\ 0, & i \neq j \end{cases}$$

- **矩阵乘法里的数字“$1$”**：任何矩阵 $A$ 乘以维度匹配的单位矩阵，结果都完全不变（$AI = A$ 且 $IA = A$），就像实数乘法里的 $a \times 1 = a$。
- **几何意义上的原地不动**：把单位矩阵当作线性变换作用在任何向量 $\mathbf{x}$ 上，得到的输出还是它自己（$I\mathbf{x} = \mathbf{x}$）——既不旋转、不缩放，也不做任何偏移。
- **标准的坐标系基底**：把 $I_n$ 按列拆开，每一列刚好就是空间中的标准坐标轴单位向量 $\mathbf{e}_1, \mathbf{e}_2, \dots, \mathbf{e}_n$（比如三维空间里的 $[1,0,0]^\top, [0,1,0]^\top, [0,0,1]^\top$），因此它本身也是最天然的正交矩阵。
# 标准正交基Orthonormal Basis 

**标准正交基**是线性空间中最“干净、最理想”的坐标系：它由一组**两两互相垂直**（正交）且**自身长度都为 $1$**（标准/单位化）的基向量组成。


在 $n$ 维欧几里得空间 $\mathbb{R}^n$ 中，一组向量 $\{\mathbf{q}_1, \mathbf{q}_2, \dots, \mathbf{q}_n\}$ 被称为标准正交基，必须同时满足：

1. **是空间的一组“基”（Basis）**：这 $n$ 个向量线性无关，空间中的**任意**一个向量 $\mathbf{v} \in \mathbb{R}^n$ 都可以唯一地写成它们的线性组合（即它们足以张成整个 $n$ 维空间，没有任何方向上的盲区）。
2. **两两正交（Orthogonal）**：任意两个不同向量的内积（点积）为 $0$，几何上表示它们严格成 $90^\circ$ 垂直：
    $$\mathbf{q}_i^\top \mathbf{q}_j = 0 \quad (i \neq j)$$
3. **单位长度 / 标准化（Normal）**：每个向量自己的 $L_2$ 范数（长度）都等于 $1$：
    $$\Vert{}\mathbf{q}_i\Vert{}_2 = \sqrt{\mathbf{q}_i^\top \mathbf{q}_i} = 1$$
用克罗内克 $\delta$ 符号写出来就是：
$$\mathbf{q}_i^\top \mathbf{q}_j = \delta_{ij} = \begin{cases} 1, & i = j \\ 0, & i \neq j \end{cases}$$
- **最常见的标准基（自然基）**：$$\mathbf{e}_1 = \begin{bmatrix} 1 \\ 0 \\ 0 \end{bmatrix}, \quad \mathbf{e}_2 = \begin{bmatrix} 0 \\ 1 \\ 0 \end{bmatrix}, \quad \mathbf{e}_3 = \begin{bmatrix} 0 \\ 0 \\ 1 \end{bmatrix}$$
    这就是我们日常熟悉的 $x, y, z$ 三个互相垂直的坐标轴，每个轴的刻度单位长度为 $1$。

如果在一个**歪斜的普通坐标系**（非正交基）里，要把一个向量 $\mathbf{v}$ 分解成各个基向量的分量 $\mathbf{v} = c_1 \mathbf{b}_1 + c_2 \mathbf{b}_2 + \dots + c_n \mathbf{b}_n$，你必须去解一个复杂的线性方程组（本质上要算矩阵求逆 $B^{-1}\mathbf{v}$）。
但在**标准正交基**下，所有坐标轴互不干扰，求第 $i$ 个坐标分量 $c_i$ 只需要做一次**简单的向量点积（正交投影）**：
$$c_i = \mathbf{q}_i^\top \mathbf{v}$$
因此，任意向量 $\mathbf{v}$ 的基展开式可以直接写出：
$$\mathbf{v} = (\mathbf{q}_1^\top \mathbf{v})\mathbf{q}_1 + (\mathbf{q}_2^\top \mathbf{v})\mathbf{q}_2 + \dots + (\mathbf{q}_n^\top \mathbf{v})\mathbf{q}_n$$

- **几何意义**：想看向量 $\mathbf{v}$ 在某个坐标轴 $\mathbf{q}_i$ 上有多长，直接拿手电筒垂直照下去看影子长度（内积）就行了，不需要管其他坐标轴怎么倾斜。
- **与正交矩阵的闭环**：把一组标准正交基 $\{\mathbf{q}_1, \dots, \mathbf{q}_n\}$ 竖着拼成一个方阵 $Q = [\mathbf{q}_1, \dots, \mathbf{q}_n]$，**得到的就是正交矩阵**。用 $Q^\top$ 左乘向量 $\mathbf{v}$，本质上就是一次性算出 $\mathbf{v}$ 在这组新标准正交基下的所有新坐标 $[c_1, \dots, c_n]^\top$。

# Transpose转置

对于任意一个 $m \times n$ 的矩阵 $A$（不需要是方阵），它的转置记作 $A^\top$（或 $A^T$），是一个 $n \times m$ 的矩阵。其定义是**把原矩阵的第 $i$ 行变成新矩阵的第 $i$ 列**（即沿着主对角线翻折）：
$$(A^\top)_{ij} = A_{ji}$$
- **核心性质**： 
    - **行向量与列向量互化**：列向量 $\mathbf{x} \in \mathbb{R}^{n \times 1}$ 转置后变成行向量 $\mathbf{x}^\top \in \mathbb{R}^{1 \times n}$，因此两个向量的内积可以写成矩阵乘法 $\mathbf{x}^\top \mathbf{y}$。
    - **乘积转置的“穿脱鞋原则”**：$(AB)^\top = B^\top A^\top$。
    - **对偶空间 / 伴随算子视角**：在欧氏空间内积下，矩阵 $A$ 作用在左边，等价于 $A^\top$ 作用在右边：$$\langle A\mathbf{x}, \mathbf{y} \rangle = (A\mathbf{x})^\top \mathbf{y} = \mathbf{x}^\top A^\top \mathbf{y} = \langle \mathbf{x}, A^\top \mathbf{y} \rangle$$


# $\det(A)$（行列式，Determinant）

$\det(A)$ 是一个针对**方阵** $A \in \mathbb{R}^{n \times n}$ 计算出来的**标量（单一实数）**，有时也记作 $\vert{}A\vert{}$。

- **几何本质（体积缩放倍率）**： 把 $A$ 看作一个空间变换，把原始空间中体积为 $1$ 的标准单位立方体（由坐标轴单位向量围成）丢进变换 $A$ 里，它会变成一个斜拉的平行多面体。**$\vert{}\det(A)\vert{}$ 就是变换后新几何体的体积（2D 情况下是面积）**，而正负号表示空间手性（定向）是否发生了镜像翻转：
    - $\vert{}\det(A)\vert{} > 1$：空间被整体放大了。
    - $0 < \vert{}\det(A)\vert{} < 1$：空间被整体缩小了。
    - **$\det(A) = 0$**：空间被彻底拍扁成了没有体积的低维图形（比如 3D 立方体被压成了一个 2D 纸片甚至 1D 线段）。
- **代数计算**：
    - **$2 \times 2$ 矩阵**：主对角线乘积减去副对角线乘积$$\det \begin{bmatrix} a & b \\ c & d \end{bmatrix} = ad - bc$$
    - **$3 \times 3$ 及更高维矩阵**：通常按某一行（或列）进行拉普拉斯余子式展开，或者先用高斯消元化成上三角矩阵，再把主对角线元素全部相乘。

**秩（Rank）**，记作 $\text{rank}(A)$，代表矩阵 $A$ 中**真正独立、不冗余的信息维度**（即最大线性无关列向量的个数，也等于最大线性无关行向量的个数）。
- **什么是“满秩”**： 对于一个 $m \times n$ 的矩阵，它的秩最大不可能超过行数和列数中较小的那个（$\text{rank}(A) \le \min(m, n)$）。当秩达到这个理论上限时，就叫**满秩**：$$\text{rank}(A) = \min(m, n)$$
    - 如果是 **$n \times n$ 方阵**，满秩意味着 $\text{rank}(A) = n$：它的 $n$ 个列向量全部线性无关，没有任何一列可以由其他列线性组合出来，它们足以撑起整个 $n$ 维空间（输出空间没有维度塌缩）。
    - 如果 $\text{rank}(A) < \min(m, n)$，则称为**秩亏（Rank-Deficient）**，说明矩阵内部存在冗余列，变换后会丢失维度


# 奇异性（Singularity）

**奇异性**只针对**方阵**讨论，描述的是方阵“是否不可逆（退化）”的性质：
- **奇异矩阵（Singular Matrix）**：**没有逆矩阵**的方阵。之所以叫“奇异（Singular，意为病态、特殊、退化）”，是因为在连续空间中随机生成一个实数矩阵，它几乎总是可逆的；只有当它的列向量恰好共线或共面（发生退化）时，才会在特定情况下出现不可逆，这在数学上属于一种“特殊退化状态”。
- **非奇异矩阵（Non-singular Matrix）**：**存在逆矩阵**的正常方阵。


对于任意一个 $n \times n$ 方阵 $A$，以下陈述在数学上**完全等价**（只要一个成立，其余全部自动成立）：

| **状态对比** | **正常状态（可逆）**                                                | **退化状态（不可逆）**                                                                   |
| -------- | ----------------------------------------------------------- | ------------------------------------------------------------------------------- |
| **奇异性**  | **非奇异**（Non-singular）                                       | **奇异**（Singular）                                                                |
| **矩阵的秩** | **满秩**（$\text{rank}(A) = n$）                                | **秩亏**（$\text{rank}(A) < n$）                                                    |
| **行列式**  | **$\det(A) \neq 0$**                                        | **$\det(A) = 0$**                                                               |
| **几何表现** | 空间无维度丢失，可还原（存在 $A^{-1}$）                                    | 空间被拍扁降维，信息丢失，无法还原                                                               |
| **典型例子** | $\begin{bmatrix} 2 & 0 \\ 0 & 3 \end{bmatrix}$（面积放大 6 倍，可逆） | $\begin{bmatrix} 1 & 2 \\ 2 & 4 \end{bmatrix}$（第二列是第一列的 2 倍，把平面压成直线，$\det = 0$） |
# Inverse Matrix

逆矩阵只针对**方阵**（$n \times n$）定义。如果存在一个 $n \times n$ 矩阵 $B$，使得它与方阵 $A$ 相乘后能把 $A$ 彻底“抵消”为单位矩阵 $I$：
$$AB = BA = I$$
那么 $B$ 就称为 $A$ 的逆矩阵，记作 $A^{-1}$。
- **物理与几何直觉（“撤销键”）**： 把矩阵 $A$ 看作一个线性变换（例如：旋转、拉伸、剪切），输入向量 $\mathbf{x}$ 得到输出 $\mathbf{y} = A\mathbf{x}$。逆矩阵 $A^{-1}$ 就是这个变换的**逆向操作**，能把 $\mathbf{y}$ 精准还原回原来的 $\mathbf{x}$：$$A^{-1}\mathbf{y} = A^{-1}(A\mathbf{x}) = I\mathbf{x} = \mathbf{x}$$
- **存在条件（非奇异性）**： 不是所有方阵都有逆矩阵。只有当 $A$ **满秩**（即行列式 $\det(A) \neq 0$，所有列向量线性无关）时，$A^{-1}$ 才存在。
    - **反例（不可逆 / 奇异矩阵）**：如果 $A$ 把三维空间压扁成了一个二维平面（降维打击，信息丢失），那你永远无法只凭平面上的影子还原出原本的高度，因此 $A^{-1}$ 不存在。
- **2×2 矩阵求逆公式**：
    $$A = \begin{bmatrix} a & b \\ c & d \end{bmatrix} \quad \Longrightarrow \quad A^{-1} = \frac{1}{ad - bc} \begin{bmatrix} d & -b \\ -c & a \end{bmatrix} \quad (ad - bc \neq 0)$$
# **正交矩阵Orthogonal Matrix**：$Q^\top = Q^{-1}$

| **维度**   | **转置 A⊤**                            | **逆矩阵 A−1**                        |
| -------- | ------------------------------------ | ---------------------------------- |
| **适用形状** | 任意 $m \times n$ 矩阵                   | 仅限满秩 $n \times n$ 方阵               |
| **运算本质** | 索引交换 $(i, j) \leftrightarrow (j, i)$ | 变换的逆映射（撤销操作）                       |
| **计算代价** | 几乎为零（内存视图/步长重排，无需浮点计算）               | 极高（通常需高斯消元或 LU/QR 分解，复杂度 $O(n^3)$） |

**正交矩阵之所以如此宝贵，正是因为它让“最便宜的操作（转置）”直接等于“最昂贵的操作（求逆）”**：因为正交矩阵只做旋转和翻转，没有拉伸也没有压扁，所以要“撤销”一次旋转，只需要反向转回去，在代数上恰好就是把行列互换（$Q^\top = Q^{-1}$），完全免去了 $O(n^3)$ 的求逆开销。

---


将 $Q$ 按列拆分为 $n$ 个列向量 $Q = [\mathbf{q}_1, \mathbf{q}_2, \dots, \mathbf{q}_n]$，则 $Q^\top Q = I$ 的第 $(i, j)$ 个元素要求：

$$\mathbf{q}_i^\top \mathbf{q}_j = \delta_{ij} = \begin{cases} 1, & i = j \\ 0, & i \neq j \end{cases}$$

这意味着正交矩阵的**所有列向量（以及行向量）构成 $\mathbb{R}^n$ 的一组标准正交基（Orthonormal Basis）**：
* **正交性**：任意两个不同的列向量互相垂直（内积为 $0$）。
* **单位长度**：每个列向量的 $L_2$ 范数都为 $1$（$\Vert{}\mathbf{q}_i\Vert{}_2 = 1$）。


**正交矩阵在理论推导和科学计算中极为重要，原因在于其完美的保结构特性：**

* **保内积与保范数（Isometry）**：对任意向量 $\mathbf{x}, \mathbf{y} \in \mathbb{R}^n$，变换后内积和 $L_2$ 范数严格不变：

$$(Q\mathbf{x})^\top (Q\mathbf{y}) = \mathbf{x}^\top (Q^\top Q) \mathbf{y} = \mathbf{x}^\top \mathbf{y}, \quad \Vert{}Q\mathbf{x}\Vert{}_2 = \Vert{}\mathbf{x}\Vert{}_2$$

* **行列式为 $\pm 1$**：由 $\det(Q^\top Q) = \det(Q)^2 = \det(I) = 1$ 可得 $\det(Q) = \pm 1$。
* $\det(Q) = +1$：纯旋转（属于特殊正交群 $SO(n)$）。
* $\det(Q) = -1$：包含奇数次镜像反射（瑕旋转）。

---

1.  $\det(Q) = +1$：纯旋转（保持空间“手性”）

- 在几何上，这叫**保持空间定向（Orientation-preserving）**。
- 这类变换可以**从“原地不动（单位矩阵 $I$）”开始，通过连续不断地微调角度平滑过渡得到**。因为单位矩阵 $\det(I) = +1$，连续变化过程中行列式不能从 $+1$ 突然跳变成 $-1$（中间必须经过 $0$，而正交矩阵行列式不能为 $0$），所以纯旋转的行列式永远锁定在 $+1$。
- **特殊正交群 $SO(n)$（Special Orthogonal Group）**：所有行列式为 $+1$ 的 $n \times n$ 正交矩阵集合，其中 "Special" 指的就是 $\det(Q) = 1$ 这个额外限制。例如在 3D 图形学和机器人学中，描述刚体姿态的旋转矩阵全部属于 $SO(3)$。

 1. $\det(Q) = -1$：包含奇数次镜像反射（颠倒空间“手性”）

- 这种颠倒空间手性（Orientation-reversing）的变换，在代数上就体现为 $\det(Q) = -1$。

因为反射的行列式是 $-1$，每多做一次变换，行列式就乘一个 $-1$：

- **1 次反射**（或 3 次、5 次……奇数次）：$$\det(Q) = (-1)^{\text{奇数}} = -1$$
    手性被颠倒了，这种“旋转 + 镜像反射”的组合在几何学和晶体学中被称为**瑕旋转（Improper Rotation，或旋转反射）**。
- **2 次反射**（偶数次）：$$\det(Q) = (-1)^2 = +1$$
    照一次镜子左右颠倒，再对着镜子照第二次镜子，左右又颠倒回来了——**两次相交轴的镜像反射，等价于一次纯旋转！** 因此偶数次反射又回到了 $\det(Q) = +1$ 的纯旋转阵营。

| **变换类型**                | **矩阵 Q**                                         | **行列式 det(Q)**                             | **几何效果**                        |
| ----------------------- | ------------------------------------------------ | ------------------------------------------ | ------------------------------- |
| **逆时针旋转 $90^\circ$**    | $\begin{bmatrix} 0 & -1 \\ 1 & 0 \end{bmatrix}$  | $0 \times 0 - (-1) \times 1 = \mathbf{+1}$ | 字母 `R` 旋转 $90^\circ$ 后还是正写的 `R` |
| **沿 $x$ 轴镜像翻转**         | $\begin{bmatrix} 1 & 0 \\ 0 & -1 \end{bmatrix}$  | $1 \times (-1) - 0 \times 0 = \mathbf{-1}$ | 字母 `R` 翻转后变成了左右颠倒的镜像 `Я`        |
| **先沿 $x$ 轴翻，再沿 $y$ 轴翻** | $\begin{bmatrix} -1 & 0 \\ 0 & -1 \end{bmatrix}$ | $(-1) \times (-1) - 0 = \mathbf{+1}$       | 两次镜像反射 = 逆时针纯旋转 $180^\circ$     |

---


* **特征值模长为 $1$**：$Q$ 的所有复特征值 $\lambda$ 都落在复平面的单位圆上（$\vert{}\lambda\vert{} = 1$）。
* **极佳的数值稳定性**：由于矩阵的谱范数 $\Vert{}Q\Vert{}_2 = 1$ 且 $\Vert{}Q^{-1}\Vert{}_2 = \Vert{}Q^\top\Vert{}_2 = 1$，其 $L_2$ 条件数 $\kappa_2(Q) = \Vert{}Q\Vert{}_2 \Vert{}Q^{-1}\Vert{}_2 = 1$，达到了所有非奇异矩阵的理论最小值。在数值线性代数（如 QR 分解、Householder 变换）及深度学习（如缓解梯度消失/爆炸、状态空间模型的旋转参数化）中，正交矩阵能防止舍入误差放大或信号能量衰减。

| 类型          | 矩阵形式                                                                                | 几何意义                         |
| ----------- | ----------------------------------------------------------------------------------- | ---------------------------- |
| **2D 旋转矩阵** | $\begin{bmatrix} \cos\theta & -\sin\theta \\ \sin\theta & \cos\theta \end{bmatrix}$ | 逆时针旋转 $\theta$ 角（$\det = 1$） |
| **镜像反射矩阵**  | $\begin{bmatrix} 1 & 0 \\ 0 & -1 \end{bmatrix}$                                     | 沿 $x$ 轴翻转（$\det = -1$）       |
| **置换矩阵**    | $\begin{bmatrix} 0 & 1 & 0 \\ 0 & 0 & 1 \\ 1 & 0 & 0 \end{bmatrix}$                 | 重排坐标轴（每行每列仅有一个 $1$）          |

“正交矩阵”严格限定在**实数域** $\mathbb{R}^{n \times n}$。当推广到复数域 $\mathbb{C}^{n \times n}$ 时，对应概念称为**酉矩阵（Unitary Matrix）**，满足共轭转置等于逆矩阵：$U^* U = U^\dagger U = I$。
